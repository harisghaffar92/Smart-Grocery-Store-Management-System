# Smart Grocery Store Management System

A Python application for managing a grocery store inventory and customer sales using lists and dictionaries.

## Features
- Add new products with unique IDs
- View all available products in tabular format
- Search products by ID or Name
- Update existing stock (add quantity or set new total)
- Process customer sales with receipt generation and stock deduction
- Track sales transaction history
- Generate store summary report (total products, available stock, revenue, price extremes, low stock warnings)

## How to Run
Run the program using Python:
```bash
python grocery_store.py
```
